# C++ Week 4 — File Handling, STL & Exceptions

Solved Week 4 assignments, practice questions, and mini project.

## Assignments
1. Write data to a file and read it back — `assignments/file_write_read.cpp`
2. Store N elements in a vector and sort them — `assignments/vector_sort.cpp`
3. Store student roll and name using map — `assignments/student_map.cpp`
4. Handle division by zero using exceptions — `assignments/division_exception.cpp`

## Practice
1. Text file write/read — `practice/file_read_write.cpp`
2. Push 5 elements into `vector<int>` — `practice/vector_push.cpp`
3. Sort vector elements with `sort()` — `practice/vector_sort.cpp`
4. Store name and age using `map` — `practice/name_age_map.cpp`

## Mini Project — Employee Record Saver
A menu-driven C++ application using file handling and STL `map` to add, display, save, and load employee records. Records are persisted in `employees.txt`.

## Compile
Use C++17: `g++ -std=c++17 week4/project/employee_record_saver.cpp -o employee_records`
